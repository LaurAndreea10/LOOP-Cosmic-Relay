Problema și soluția

Animația originală era spectaculoasă, dar nu oferea obiective sau progres. LOOP păstrează particulele și atmosfera cosmică, apoi adaugă mecanici, niveluri, streak, power-up-uri, misiuni și progres persistent.

Accesibilitate

  • Space, Enter, click, atingere și switch
  • Scanare automată și zonă sigură reglabilă
  • Contrast ridicat, text mare și efecte reduse
  • Simboluri, culori și etichete text
  • Feedback vizual, sonor și haptic

Progres

  • Record și statistici pe mod
  • XP, monede, ranguri și insigne
  • Streak și multiplicator
  • Trei profiluri locale
  • Export și import JSON

Tehnologie

  • HTML, CSS și Canvas API
  • JavaScript fără framework
  • localStorage
  • Web Audio și Vibration API
  • PWA cu funcționare offline
