# LOOP — Cosmic Relay

Joc cosmic accesibil și PWA, creat de **Laura Andreea / LaurAi**. Proiectul păstrează cerculețele și traseul luminos din animația originală, apoi le transformă într-o experiență cu obiective, progres și control printr-o singură acțiune.

[Joacă versiunea live](https://laurandreea10.github.io/LOOP-Cosmic-Relay/) · [Despre proiect](https://laurandreea10.github.io/LOOP-Cosmic-Relay/about.html) · [Portofoliu](https://laurandreea10.github.io/codepen-portfolio/)

## Funcții principale

- 9 moduri: Ritm, Colectare, Reflexe, Puzzle Zen, Memorie, Pulse, Constelații, Respirație Calmă și Antrenament
- 7 trasee dinamice, niveluri cu dificultate progresivă și obiective de câte 10 reușite
- streak, combo, XP, monede, ranguri, insigne și record persistent
- power-up-uri: încetinire, scut și scor dublu
- trei profiluri locale, statistici pe mod și export/import JSON
- patru teme cosmice, sunet ambiental Zen și feedback haptic
- instalare PWA și funcționare offline

## Accesibilitate

- control prin `Space`, `Enter`, click, atingere sau switch
- scanare automată pentru utilizare cu o singură apăsare
- zonă sigură mică, medie sau mare
- mod fără timp și vieți infinite
- contrast ridicat, text mare, efecte reduse și transparență dezactivabilă
- ținte diferențiate prin culoare, formă, simbol și etichetă text
- feedback vizual, sonor și prin vibrație
- instrucțiuni ilustrate înaintea fiecărui mod și tutorial memorat local

## Rulare locală

Deschide `index.html` într-un browser modern. Pentru Service Worker și instalarea PWA, servește proiectul prin HTTPS sau un server local.

## Fișiere

- `index.html` — jocul complet
- `about.html` — prezentare și case study
- `manifest.webmanifest` — configurarea PWA
- `sw.js` — cache offline versionat
- `loop-icon.svg` — icon PWA
- `loop-social.svg` — imagine social sharing

## Confidențialitate

Progresul rămâne în browser prin `localStorage`. Nu există cont, tracking sau transfer de date către un server. Exportul progresului este inițiat exclusiv de utilizator.
