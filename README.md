LOOP — Cosmic Relay Premium
Joc cosmic accesibil, controlabil cu o singură acțiune, creat de LaurAi.

Pornire
Deschide LOOP-Cosmic-Relay.html. Pentru instalare PWA și offline, publică toate fișierele prin HTTPS (de exemplu GitHub Pages).

Moduri
Ritm, Colectare, Reflexe, Puzzle Zen, Memorie, Pulse, Constelații, Respirație Calmă și Antrenament.

Accesibilitate
Control prin Space/Enter, click sau atingere; scanare automată pentru switch; zonă sigură reglabilă; haptic; etichete text; contrast ridicat; text mare; efecte reduse; număr reglabil de particule; moduri fără timp și penalizări.

Progres
Record, XP, monede, ranguri, streak, obiective, misiune zilnică, insigne și statistici pe mod sunt salvate local. Progresul poate fi exportat JSON.

Versiuni
v1: animația LOOP cu particule pe traseul infinitului.
v2: transformare în joc accesibil cu cinci moduri.
v3 Premium: nouă moduri, progres persistent, power-up-uri, șapte trasee, profil, PWA și optimizări de accesibilitate.
